# NASA/JPL visual sources

These optimized game textures come from official NASA and NASA/JPL image pages. They are used as visual textures only; the simulator's positions, radii, masses, and gravity are calculated by the game code.

- Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune: [NASA Planetary Science](https://science.nasa.gov/solar-system/planets/)
- Earth reference: [NASA Visible Earth — The Blue Marble](https://visibleearth.nasa.gov/images/57723/the-blue-marble)
- Planet reference montage: [NASA/JPL Solar System Montage](https://science.nasa.gov/photojournal/solar-system-montage-updated/)
- Sun: [NASA Solar Dynamics Observatory](https://science.nasa.gov/photojournal/image-of-sun-from-nasas-solar-dynamics-observatory/)
- Milky Way: [NASA/JPL 2MASS Point Source All-Sky](https://www.jpl.nasa.gov/images/pia04250-point-source-all-sky/)

The Milky Way image is resized to 1920 pixels for smoother browser performance. Image credits remain with NASA, JPL, and the missions listed on each source page.
